# ขายของยังไงต่อ — 2 ทางที่ทำได้จริง

**สถานะ K (2 พ.ย. 2026):** Shopee มีบัญชีแต่ยังไม่เปิด seller · **Lazada เปิด seller แล้ว** ← ตัวนี้มีค่า

---

## ⚠️ เจอปัญหาก่อน — ต้องรู้

**ทั้ง Shopee และ Lazada ห้ามขายไฟล์ดิจิทัล (ดาวน์โหลด) ถ้ายังไม่ได้รับอนุมัติ**

- Shopee: ต้องขออนุญาตก่อน (ศูนย์ช่วยเหลือ → "สินค้าดิจิทัล")
- Lazada: ต้องขอ **Digital Goods Whitelisting** ก่อน ถึงจะลงสินค้าดิจิทัลได้

→ เครื่องคิดราคา Shopee (ไฟล์) **ลงตรง ๆ ไม่ได้** ต้องขออนุมัติก่อน

---

## ✅ ทางที่ 1 (แนะนำ) — พิมพ์เสื้อตามสั่ง ผ่าน Do.ink

**ใช้ Lazada ที่ K เปิดไว้แล้วได้เลย**

| | |
|---|---|
| ค่าสมัคร | **ฟรี** |
| ค่ารายเดือน | **ไม่มี** |
| จ่ายเมื่อไร | จ่ายเฉพาะตอนมีออเดอร์จริง |
| ต้องสต็อกไหม | **ไม่ต้อง** |
| ต้องแพ็ค/ส่งเองไหม | **ไม่ต้อง** — Do.ink ทำหมด |
| เชื่อมกับ | Shopee, **Lazada**, TikTok Shop, LINE Shop |
| ผลิต | 24-48 ชม. · ส่ง 1-3 วัน |

**หลักการ:** AF ออกแบบลายเสื้อ → K อัปโหลด → เชื่อม Lazada → ลงขาย
ลูกค้าสั่ง → Do.ink พิมพ์+แพ็ค+ส่ง → K ได้เงินเข้า Lazada

**ทำไมดี:**
- ใช้บัญชี Lazada ที่มีแล้ว (ไม่ต้องรอยืนยันตัวตนใหม่)
- **ไม่ติดปัญหาสินค้าดิจิทัล** (เป็นของจริง)
- ลูกค้าใน Lazada มีอยู่แล้ว ไม่ต้องหาเองทั้งหมด
- AF ทำลายให้ได้ (ลายตัวอักษร/ข้อความ)

**สิ่งที่ K ต้องทำ:**
1. สมัคร Do.ink (do.ink) — ฟรี
2. กด "เชื่อมร้าน" → เลือก Lazada → ล็อกอิน
3. อัปโหลดลาย (AF ทำให้)
4. ตั้งราคา → ลงขาย

## ✅ ทางที่ 2 — ขายไฟล์ดิจิทัล ผ่าน Payhip

**ถ้าอยากขายเครื่องคิดราคา (ไฟล์)**

| | |
|---|---|
| ค่าสมัคร | **ฟรี** |
| ค่าโฮส | **ไม่มี** (Payhip เก็บให้) |
| ต้องขอ whitelist ไหม | **ไม่ต้อง** |
| รับเงิน | Xendit (รองรับไทย) หรือ PayPal |
| หัก | % ต่อการขาย |

**ทำไมดี:**
- **ไม่ต้องขออนุมัติ** จาก Shopee/Lazada
- รับเงินบาทไทยได้ (Xendit รองรับประเทศไทย)
- เปิดร้านได้ทันที

**สิ่งที่ K ต้องทำ:**
1. สมัคร payhip.com — ฟรี
2. เชื่อม Xendit (ใช้บัตรประชาชน + บัญชีธนาคาร) **หรือ** PayPal
3. อัปโหลดไฟล์ + ใส่ข้อความ (AF เตรียมให้แล้ว)
4. ตั้งราคา → เปิดขาย

**จุดอ่อน:** Payhip ไม่มีคนเดินผ่าน → ต้องหาลูกค้าเอง (ยากกว่าทางที่ 1)

## 🎯 AF แนะนำ

**เริ่มทางที่ 1 (Do.ink + Lazada)** เพราะ:
- ใช้บัญชีที่ K มีแล้ว → เร็วสุด
- Lazada มีคนซื้ออยู่แล้ว → มีโอกาสขายได้จริง
- ไม่ต้องรออนุมัติอะไร
- AF ทำลายให้ได้

**แล้วค่อยทำทางที่ 2 (Payhip)** ควบคู่ สำหรับไฟล์ดิจิทัล
